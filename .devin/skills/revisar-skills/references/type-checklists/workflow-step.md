# Workflow-step

Skills que producen un artefacto principal o realizan un análisis con estructura de fases.

## Checklist requerido

- Fase 0 — Resolver entradas
- Fase A — Cargar contexto
- Fase B — Procesar/analizar
- Fase C — Escribir artefacto
- Estrategia de fallo en cada fase
- Done when claro con entregables

## Checklist recomendado

- Referencias compartidas relevantes
- Autoevaluación antes de terminar
- Handoff block si es parte de workflow

## Anti-patrones

- ❌ Fases sin output claro
- ❌ Estrategia de fallo incompleta
- ❌ Done when vago o ausente
